# esp8266_waremacode_sniffer

> **⚠️ Deprecated:** Reading Warema EWFS codes now works directly in ESPHome with **[esphome-warema-cover-hub](https://github.com/tombrain/esphome-warema-cover-hub)**, including showing them in Home Assistant. This sketch is no longer maintained.
>
> **⚠️ Veraltet:** Warema-EWFS-Codes lassen sich jetzt direkt in ESPHome mit **[esphome-warema-cover-hub](https://github.com/tombrain/esphome-warema-cover-hub)** auslesen, auch mit Anzeige in Home Assistant. Dieser Sketch wird nicht mehr gepflegt.

Arduino sketch for the ESP8266 that reads Warema EWFS codes with a 433 MHz receiver on GPIO14 and publishes them via MQTT and the serial monitor.
